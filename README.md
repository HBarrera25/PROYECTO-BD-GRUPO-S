# PROYECTO-BD-GRUPO-S
# 🏨 Sistema de Reservas de Hotel

## 📖 Descripción

Este proyecto consiste en el diseño e implementación de una base de datos para la gestión de reservas de un hotel. El sistema permite administrar habitaciones, huéspedes, reservaciones, estancias, servicios adicionales, facturación y empleados, garantizando la integridad y consistencia de la información mediante restricciones, transacciones, funciones, procedimientos almacenados y triggers.

El proyecto fue desarrollado como parte de la asignatura de **Bases de Datos Ciclo 01 2026** utilizando **PostgreSQL**.

## 📋 Contenido del Proyecto

### DDL
Script encargado de la creación de la base de datos, tablas, restricciones, llaves primarias, llaves foráneas y validaciones.

### DML
Script encargado de la inserción de datos de prueba para el funcionamiento del sistema.

### Consultas SQL
Consultas básicas y avanzadas que permiten obtener información relevante del sistema hotelero.

### Transacciones
Implementación de transacciones utilizando:
- begin
- commit
- rollback
- savepoint

### Funciones
Funciones desarrolladas en PL/pgSQL para automatizar cálculos y consultas reutilizables.

### Procedimientos Almacenados
Procedimientos para automatizar procesos de negocio como:
- Registrar reservaciones.
- Registrar check-in.
- Realizar check-out.
- Cancelar reservaciones.

### Triggers
Disparadores para:
- Validar reglas de negocio.
- Evitar inconsistencias.
- Auditar cambios importantes.
- Actualizar información automáticamente.
